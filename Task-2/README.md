# Kanban Board

## Project Description

This project is a simple Kanban Board application built with HTML, CSS, and JavaScript.

## Features

- Add Task
- Edit Task
- Delete Task
- Search Task
- Drag & Drop
- Local Storage
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## How to Run

1. Download the project.
2. Open the project folder.
3. Open `index.html` in your browser.
